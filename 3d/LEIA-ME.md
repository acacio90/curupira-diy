# Modelos 3D

Todos os modelos usados na placa estão aqui, para o projeto abrir completo em
qualquer computador (a placa aponta para eles com `${KIPRJMOD}/3d/...`).

| Arquivo | Peça | Fonte |
|---|---|---|
| `ESP32-S3-DevKitC-1.step` | DevKit (U1) | SnapMagic (modelo do N8R2, mesmas dimensões) |
| `TFT-ST7789-2.0-GMT020-02.step` | Tela 2,0" (J1) | GrabCAD |
| `CC1101-E07-M1101D-SMA.step` | CC1101 (J3) | GrabCAD |
| `NRF24L01-PA-LNA.step` | NRF24L01+PA+LNA (J9) | GrabCAD |
| `PN532-V3.step` | PN532 V3 (J2) | GrabCAD |
| `GPS-NEO-6M.step` | GPS NEO-6M (J6) | GrabCAD |
| `TP4056-USB-C.step` | Carregador TP4056 | GrabCAD |
| `microSD-substituto-OpenLog.step` | microSD (J4) — **substituto visual** (OpenLog da SparkFun) | GrabCAD |
| `kicad/*.step` | Componentes padrão (botões, resistores, barras…) | Biblioteca 3D do KiCad |

Os modelos do GrabCAD/SnapMagic pertencem aos seus autores e seguem os termos desses sites.
